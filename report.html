H. Render Architecture Selection: Option B (Unified Service)

Architecture Decision: Option B (Single Unified Web Service) was selected because it hosts both the Express API and the embedded Vite/React SPA under a single origin and port. This eliminates CORS preflight latency, guarantees reliable Server-Sent Events streaming, prevents third-party cookie restrictions, and fits within Render's free or starter plans without synchronizing dual services.

I & J. Deployment Fixes Applied

Issue Identified Impact Engineering Fix Applied
Default host binding (localhost) Render ingress router could fail to route traffic to container. Explicitly bound server to 0.0.0.0 in backend/src/server.js.
Blueprint set to plan: standard Blocked deployment on free Render accounts ($25/mo paywall). Updated render.yaml to plan: free.
Static AI client initialization Keys added in Render dashboard required manual server reboots. Implemented dynamic getClient() lazy-loading across all 3 AI providers.
Unmatched API route fallthrough Unmatched /api/* requests returned plaintext HTML. Added explicit JSON 404 handler in backend/src/app.js.
Single-depth dotenv path Could fail to find .env depending on CLI execution directory. Added multi-path resolution in backend/src/config/env.js.
Client API base URL edge cases Potential double slashes or missing /api prefixes. Created centralized getApiBaseUrl() in frontend/src/services/api.js.

L. Exact Render Deployment Instructions

Method 1: Automated Blueprint (Recommended)

  1. Navigate to Render Dashboard and click New + → Blueprint.
  2. Select your GitHub repository containing UMNY AI.
  3. Render reads render.yaml automatically.
  4. Fill in the prompted environment variables:
    • MONGODB_URI: Your MongoDB Atlas connection URI
    • INITIAL_ADMIN_PASSWORD: Choose your admin account password
    • GEMINI_API_KEY / OPENAI_API_KEY / ANTHROPIC_API_KEY: Your provider keys
  5. Click Apply to trigger the automated build and launch.
